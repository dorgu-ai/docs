## Synopsis

```bash
dorgu version
```

Print the Dorgu CLI version, git commit hash, and build date.

## Description

The `version` command outputs build metadata embedded at compile time. This is useful for verifying which release you are running, reporting bugs, or confirming that an upgrade was applied.

## Example output

```
dorgu version v0.9.0
Build: e8a7352 @ 2026-08-16T17:08:49Z
```

The commit and date are stamped in by the release build, so you only see them when the binary came from a release archive or from a local `make build` / `make install`.

`go install github.com/dorgu-ai/dorgu/cmd/dorgu@...` cannot set those linker flags, so it prints:

```
dorgu version v0.9.0
Build: from source
```

That is a working install, not a broken one. See [installation](/cli/installation#verify-installation).
