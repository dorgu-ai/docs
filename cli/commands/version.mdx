---
title: dorgu version
description: Display Dorgu CLI version information
---

## Synopsis

```bash
dorgu version
```

Print the Dorgu CLI version, git commit hash, and build date.

## Description

The `version` command outputs build metadata embedded at compile time. This is useful for verifying which release you are running, reporting bugs, or confirming that an upgrade was applied.

## Example output

```
dorgu version v0.8.0
Build: d4d7983 @ 2026-07-09T01:15:55Z
```

When the binary is built from source without release metadata, the second line reads `Build: from source`.
